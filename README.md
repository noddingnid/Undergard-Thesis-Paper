# Undergard-Thesis-Paper
Detection and prediction of epileptic seizure using different machine learning classifiers (Python, Scikit-learn, PCA,
K-means) – Investigated automated epileptic seizure detection using EEG signals for early identification of
seizure-related patterns. Implemented and compared six machine learning classifiers, including SVC, Logistic
Regression, Decision Tree, Random Forest, Gradient Boosting, and MLP, across five subject groups. Achieved a
95.90% F1-score using Random Forest. Further explored PCA-based dimensionality reduction and K-means
clustering to evaluate their impact on classification performance, finding no significant improvement over the
original feature set.
